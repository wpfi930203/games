# 🎮 Games · 小游戏合集

## 超级马力欧银河大电影

单文件 HTML5 Canvas 横版闯关游戏 —— **双击 `mario-galaxy-game.html` 即可开玩**，无需安装、无需联网、无任何依赖。

### 玩法

| 操作 | 键盘 | 触屏 |
|---|---|---|
| 移动 | `←` `→` / `A` `D` | 屏幕左下方向键 |
| 跳跃 | `空格` / `Z` / `↑` | 右下方「跳」 |
| 重力翻转 | `X` / `Shift` | 右下方「翻」 |
| 旋转攻击 | `C` / `Ctrl` | 右下方「转」 |
| 暂停 / 重开 / 音乐 | `Esc` / `R` / `M` | 左上「☰ 控制」菜单 |

### 内容

- **6 个关卡**，6 套主题（含极光、熔岩、星空等）与天气层
- 力量星、彩虹星（彩蛋）、金币、敌人、尖刺、横移/竖移平台
- **重力翻转**机制：踩上重力板即可翻转重力，在天花板上行走
- WebAudio 合成 BGM 与音效（无音频文件）
- 通关结算：**王子·马力欧**与**公主·碧姬**双角色庆祝动画
- 页面内自检：打开 `mario-galaxy-game.html?test=1` 运行 28 项引擎自检

### 说明

- 移动端请横屏游玩，竖屏会提示旋转设备
- 也提供微信小程序版本（WXML/WXSS 工程，需用微信开发者工具运行）

## NEON-RUSH · 3D 霓虹赛车

第三人称 **3D 赛车游戏**（Three.js + cannon-es）—— **双击 `neon-rush.html` 即可开玩**，无需安装、无需联网。完整源码在 `neon-rush/` 目录。

### 玩法

| 操作 | 键盘 | 触屏 |
|---|---|---|
| 驾驶 | `W A S D` / 方向键 | 左侧虚拟摇杆 |
| 氮气加速 | `Shift` | 右侧「氮气」按钮 |
| 手刹 | `空格` | 右侧「刹车」按钮 |
| 切换视角 / 复位 / 调试面板 | `C` / `R` / `G`(或 `` ` ``) | — |

### 内容

- **三种模式**：竞速（3 名 AI 对手）、计时赛（幽灵车影子竞速）、竞技场（战斗模式）
- 车辆物理：加速 / 刹车 / 转向 / 手刹 / 氮气，含悬挂与轮胎抓地力模拟
- 低多边形风格、可自定义车色、自带阴影；粒子特效（轮胎烟雾 / 尾焰 / 扬尘 / 爆炸）
- 昼夜循环与天气系统；HUD（速度表 / 计时 / 名次 / 小地图 / 血条）、第三人称跟随镜头
- 移动端优先：实例化网格渲染、虚拟摇杆 + 按钮、撞击触觉反馈

### 说明

- 触屏设备请横屏游玩
- 开发版运行：`cd neon-rush && npm install && npm run dev`
